# P22 — the bounce land's own choice, the reveal-then-choose road, and a filler spell that cannot be retargeted

Wave 22. Generator side is `MtgEngine.Cards.Pipeline/Scenarios/**`; the tests are
`tests/MtgEngine.Pipeline.Tests/ScenarioStageTests.Wave22.cs` and the two withheld tests in
`.Remembered.cs`, each road played through `Subsystems.Wave2()`. The wave-21 failure is gone and
the reveal-then-choose card is staged. **One engine ask**, § 3: `ChangeTarget` cannot retarget the
new `ScenarioFiller.Bolt`, so the two cards it was added for are still without a scenario.

## 1. The land whose enters-trigger returned itself (CR 603.3) — no ask

`ee723c7c` (Guildless Commons) failed `InZone was Hand`. The runner answered the trigger's "return a
land you control" with the first legal option (`ScenarioAnswers.FirstLegal`), and the caster's
battlefield was empty until the card under test arrived on it, so the only land its controller had
was the card itself — the play reported the card bouncing itself as the card failing.

The runner **does** offer the choice before it picks: `Query.Candidates` orders by object id and
`ZoneSystem` mints a new id when a card changes zones (CR 400.7), so a permanent the *setup* placed
is older than the card once that card has been played. Standing one there is enough, and no R-series
ask is needed. `SmokeBoard.Bystander` places it under an alias of its own (`stood-1`) — not a target,
nothing announces it — and `SmokeScenario.Enters` reads the card's own enters-trigger: a
`Move { What: Choose { ControlledBy: You }, To: Hand }` stands a filler of the kind the filter admits
on the caster's battlefield and expects **that** card in hand. The land arm asserted only the arrival
before, which for this card was the wrong half of it.

Nothing is refused in that arm: a trigger the board cannot stage leaves the play asserting the
arrival, which is all a land's scenario ever asserted. A filter naming what an *opponent* controls
stands nothing (a body on the caster's side would assert a bounce the trigger could never have made)
— there is a test for that.

## 2. `Reveal` the top X, then choose among them (CR 701.15, 700.2) — no ask

P19's three arms, never committed, are written fresh in `SmokeScenario.Remembered.cs`:

- **the reveal** remembers how many cards it will show (`SmokeBoard.Reveals`) and stocks nothing —
  what they have to be is the business of the step that chooses among them;
- **the choice** stocks the top of the library with what the reveal will show: one card
  `SmokeFillers.Findable` admits and the rest `SmokeFillers.Unfindable` refuses, so the question has
  exactly one option and the expectation names the card it took rather than counting a battlefield.
  Each is remembered under the reveal's key and the one taken under the choice's own key;
- **the rest** (`Move { Each { In: Library, Also: AllOf [IsRemembered k1, not IsRemembered k2] } }`)
  reads the difference between those two sets and expects each of them in the caster's graveyard.
  Any other predicate is null: which cards a filter the board cannot read describes is not a
  generated scenario's to guess.

**X is announced as two, not one** (`RevealedX`), because a reveal of one card has no "rest" for the
last step to move and the third arm would assert nothing. A count of X raises what the cast is going
to announce, so every filter bounded by X — including this card's `manaValue <= X` — is read against
the number that was named. Both corpus cards with a `Reveal` were re-verified: `e2487868` **1/1** and
`c02c5547` **1/1**.

E9p is what made this playable: `permanent: true` read against a card in a library now answers
whether it has a permanent card type (CR 110.4c), so the choice has an option at all.

## 3. `ChangeTarget` cannot retarget an "any target" spell, and cannot move a target from one player to another (E-series)

`c20a96f7` (Bolt Bend) and `30ec73ad` (Imp's Mischief) are both
`ChangeTarget { What: Target { In: Stack }, AllTargets: false }`. `ScenarioFiller.Bolt` is on
`card-engine` as asked — an instant for `{R}` with `DealDamage(Fixed 1, AnyTarget)` — and it still
cannot be retargeted. `EffectInterpreter.Retargeted` (`EffectInterpreter.Retarget.cs`) asks its
question only when `entry.Targets.Count > 0` **and** `Candidates(...).Count > 0`, and neither holds:

1. `var count = entry.Targets.Count` counts the **object** targets only, so a bolt aimed at a player
   — which is what the scenario wants, so the life totals say which player took the damage — has a
   count of zero and the whole effect returns silently. `Retarget` then writes
   `new StackTargetsChanged(spell, targets, entry.TargetPlayers)`, passing the player list through
   unchanged, so no answer could move a target from one player to another even if the question were
   asked. CR 115.7 changes *a target*, and CR 115.1 makes a player one.
2. `Candidates` reads `FilterAt(filters, 0)`, which is **null for an `AnyTarget` slot** (CR 115.4),
   and returns nothing — so a bolt aimed at a *creature* offers no new targets either. The `Legal`
   check two methods above already says an `AnyTarget` slot "admits any object still in the game";
   `Candidates` does not agree with it.

**Ask** (CR 114.6, 115.7a): for an `AnyTarget` slot the candidates are the same set the announcement
reads (`Query.Targets.cs` answers it — creatures, planeswalkers, battles and the players); the
question's count includes `entry.TargetPlayers`; the options carry players (`ChoiceOption.Player` is
already in the record); and `StackTargetsChanged` carries the new player list. With that in, the
generator's arm is small: the opponent casts the Bolt at the caster, the card under test targets the
Bolt, and the play expects `Life(A, 20)` and `Life(B, 19)` — which fails without the retarget, so it
is a real assertion and not one that always passes.

Until then both cards keep **no scenario** rather than one that reveals the runner's own gap
(the P16 rule). This is the fourth wave these two have waited (P16 § 3, P19 § 5, P20 § 4, P21 § 3);
the filler was the half the coordinator could add without the engine, and this is the other half.
