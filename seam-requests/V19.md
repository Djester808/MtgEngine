## Decisions taken here

- **`LoseLife` is a flag on `PlayerRestriction`, not a `CantLoseLife` record.** `CantGainLife` is a
  record because it predates the flag set; the flag set is the shape for the rest, and this card
  prints four prohibitions in one sentence ("can't lose life ... can't lose the game or win the game").
- **`PlayerHexproof` is a record and not `PlayerCant(BeTargeted)`, though CR 702.11c forbids exactly
  what CR 115.6 forbids.** The difference is not what it stops but what other cards can see: hexproof
  is looked for, granted and taken away by name (702.11e), and an anonymous restriction is invisible
  to all of it. The precedent is `PlayerProtectionFromEverything`, which sits beside the Protection
  keyword for the same reason.
- **The trigger cause is a `Trigger`, not an `ObjectFilter`.** "A land entering" is an event, and an
  object filter cannot say which event it was part of. It also keeps the record generic: any cause a
  trigger can describe is sayable without a second field.
- **`MoreThanEachOtherPlayer` is a condition over an `Amount` and a `PlayerFilter`, one record for
  every card that prints the shape** — cards in hand, lands, life, creatures. `Others` is optional
  because the printed line is nearly always "each other player".
- **The free cast is an alternative cost with a flag, and the empty `Costs` is its companion.** A
  nullable `Cost` would have changed a required field every reader in `MtgEngine.Rules` dereferences;
  the flag is additive and every stored card file still reads.
- **CR numbers, every one read in `comprehensive-rules.txt` first.** Corrections to the brief: the
  player half of hexproof is **702.11c** (702.11d is "hexproof from [quality]", which is defined for
  permanents only); "triggers an additional time" is **603.2d** and not 603.2; life loss is
  **119.3** (119.2 is damage causing it, 119.4 is life paid as a cost); the Aven Mindcensor rule is
  **701.23f**, which names that exact card in its example.
