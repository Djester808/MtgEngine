# V11 — wave 19 vocabulary: the nine shapes three independent translators each hit on the first corpus slice

All nine landed in `MtgEngine.Cards` this wave, lint where two halves of a record can contradict
each other or say nothing, round-trip in `VocabularyAdditionsTests.Wave19.cs` (16 tests), and have a
one-spelling line in `TranslationPrompt.LaterSpellings` (proved by
`TranslationPromptTests.Every_wave_nineteen_record_has_a_one_spelling_line`). **`IrVersion` is
unchanged at 1.** Seven of the nine are new records; the other two are optional fields on records
that already existed (`DelayedTrigger.Until`, `LoseLife.StoreAs`, `BecomesCopyOf.ExceptThisAbility`,
`Face.AlternativeCosts`), so every stored card file still reads and there is nothing to migrate.
`ZoneChange` is the one widening — `To` became optional — and that is argued below. The schema
snapshots under `cards/schema/` are regenerated (`UPDATE_SCHEMA=1`, the deliberate road, as V8–V10
did); nothing else under `cards/` was touched. The prompt renders (`pipeline prompt`, 621 lines).

Nothing here is played by anything yet. Each row names the card it unblocks and the arm that has to
read it.

## Decisions taken here

- **`ZoneChange.To` became optional rather than gaining a second record.** "Leaves your graveyard"
  is one trigger about one event; a `LeavesZone` record beside `ZoneChange` would be a second
  spelling of the same sentence and the translator would have to pick, which is exactly the
  disagreement the one-spelling rules exist to stop. The widening costs nothing stored: every card
  file written so far sets `to`, and a required field becoming optional needs no migration, so
  **`IrVersion` stays at 1** — bumping it would mark all 192 pilot files stale for a change no
  reader has to act on.
- **`NotFrom` is a field, not a condition.** A `TriggeredAbility.If` about where the object came
  from tests nothing: by the time the condition is read the object has moved, and the graveyard copy
  is a new object (CR 400.7, 603.10). The exclusion has to sit in the trigger.
- **The damage floor is a `ContinuousEffect`, not a `ReplacedEvent`.** Damage replacements in this
  vocabulary are continuous effects — `PreventDamage`, `DamageMultiplier` — applied to a player or
  object with a duration; a `ReplacedEvent` would need a `With` effect, and "reduces it to 1
  instead" is not an effect a card can write. `Floor` is an `Amount` so a card that prints another
  number, or one that computes it, needs no new record.
- **The alternative cost is on the `Face`, not on an `Ability`.** It is an option offered as the
  spell is cast, before any ability of the object exists, and the face already carries the other two
  casting riders (`AdditionalCosts`, `CastOnlyIf`). It is a plain record (`AlternativeCost`) beside
  `CounterSpec` and `SearchDestination`, and it is appended **last** in `Face`'s parameter list so
  no positional construction anywhere shifts.
- **"Life lost this way" is a `StoreAs` key, not an `Amount` of its own.** The vocabulary already
  says "the number of cards discarded this way" as `Stored`, and the linter already collects any
  `StoreAs` as a produced key (so L003 works with no change). A `LifeLostThisWay` amount would be a
  second spelling of `Stored` and would have to guess which earlier step it meant.
- **The opening-hand permission is a `ContinuousEffect` with `Where: Hand`, not a new `Ability`
  kind.** CR 103.6 abilities are static abilities that function from the hand; `StaticAbility`
  already carries `Where`, and the lint pins it, so the ability list is untouched.
- **Lint codes L025–L029.** L025 `ZoneChange` (both `From` and `NotFrom`; no zone at all),
  L026 `AlternativeCosts` (an empty list; an alternative that asks for nothing, which would make the
  spell free), L027 `MayBeginGameOnBattlefield` outside a hand-scoped static ability,
  L028 `TriggeringDamage` in an ability that does not trigger on damage, L029 `ExceptThisAbility` on
  a static or spell ability. They live in a fourth partial, `Linter.Wave19.cs`; `Linter.cs` is at
  494 lines and calls `CheckWave19` beside `CheckPermissions`/`CheckConditionals`, plus
  `CheckAlternativeCosts` per face (the only check of the five that is not per ability).
- **`RuleRef`s added**: `DrawnThisTurn` 121.1, `AttacksWithCreatures` and `AttackersAgainst` 508.1,
  `TriggeringDamage` 603.10, `DamageDoesNotReduceLifeBelow` 120.4, `MayBeginGameOnBattlefield`
  103.6, `AlternativeCost` 118.9. `ZoneChange` keeps 603.6, `DelayedTrigger` 603.7,
  `BecomesCopyOf` 707, `LoseLife` 119.

## Asks (outside `MtgEngine.Cards/**`)

1. **E-series (trigger system)** — `TriggerMatching.Moved` must read `To` as optional and honour
   `NotFrom`, and `From` past the battlefield (row 2). This is the one place an existing reader
   changes behaviour rather than gaining one; without it Syr Konrad's two lines match nothing.
2. **E-series (replacement system)** — the damage floor (row 3), ordered by CR 616 with the other
   damage replacements.
3. **E-series (casting system)** — the face-level alternative costs at announcement (row 4), one at
   most per cast, and `PaidAlternativeCost` answering for it.
4. **E-series (interpreter)** — `LoseLife.StoreAs` (row 8), `TriggeringDamage` and
   `DelayedTrigger.Until` (row 7), and the `AttackersAgainst` amount (row 6).
5. **E-series (query)** — the `DrawnThisTurn` predicate (row 1), which needs the turn's draws kept
   per player.
6. **E-series (continuous effects)** — `BecomesCopyOf.ExceptThisAbility` (row 9).
7. **Runner / coordinator** — the CR 103.6 offer before the first turn (row 5); no other arm can
   make it, because it happens outside any turn.
8. **P-series (reference)** — `VocabularyReference.cs`'s root section is hand-written and not owned
   here: add `typeof(AlternativeCost)` beside `SearchDestination` and `CounterSpec` so the
   translator sees its two parameters as a line of their own. Until then the fields are named in the
   `Face` doc, the one-spelling line and the output rule (which already lists it as a plain object).
9. **Coordinator / pipeline** — refresh both `system.md` files (the prompt text changed in two
   places, so the prompt version moved) and redo the nine cards on three models. A reading that
   spells any of these as an `If` around the record, as two records, or as an `Unsupported` is now a
   real disagreement and not a canonical rewrite.

## Not done in this box

- **No lint that a `ZoneChange` from the battlefield to a graveyard should be `Dies`.** It is a real
  second spelling, but pilot files already carry it and a new Error would fail cards no one has
  re-read; it belongs to a canonical rewrite in the pipeline, not to a lint added mid-wave.
- **No lint that `AttackersAgainst` appears only in a combat-shaped ability.** The amount is legal in
  any ability that resolves during combat, and the linter cannot tell which those are.
- **No `MaxOnePerCast` check across `AlternativeCosts` entries.** The casting system enforces
  CR 601.2b at the moment of choice; a face may print two alternatives and both are legal to list.
- **The floor is not read on life loss.** If a card ever prints a floor on life loss as well, it is a
  second field on the same record, not a second record.
