## 3. "agreed among all-clean: 35/34" — **an ask, owner: `MtgEngine.Cards.Pipeline/Pilot/**`**

Not in `Agree/` and not mine to edit. The line is `Pilot/PilotReport.cs:99`:

```csharp
var agreed = results.Count(r => r.Agreement.Agreed);
var allClean = results.Count(r => r.Agreement.Lint.Values.All(lint => lint is { HasErrors: false }));
sb.AppendLine(… $"- agreed among all-clean: {agreed}/{allClean} …");
```

`agreed` counts every card that agreed; `allClean` counts only cards where **every** reading linted
clean. A card agrees on a majority of the readings that *parsed and linted clean*
(`AgreeStage.cs:84`), so a third reading with lint errors leaves the card agreed and not all-clean —
numerator over denominator. **Asked for** either

```csharp
var agreedAmongClean = results.Count(r => r.Agreement.Agreed
    && r.Agreement.Lint.Values.All(lint => lint is { HasErrors: false }));
```

used as the numerator of that one line (the honest reading of its own name), or the line renamed to
"agreed, of the cards every model linted clean" and the ratio dropped. Prefer the first: the
percentage is the number the wave reports read.
