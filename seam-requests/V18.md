## Decisions taken here

- **`Min` is a field on `Target`, not a second `Target` and not a `Count` that varies.** CR 601.2c
  fixes the number of targets once it is announced, so a range is one announcement. Two Targets
  would announce two independent choices and let the same object be chosen for both.
- **`LifeLostThisTurn` takes a `PlayerFilter` and not a `PlayerRef`**, as the brief asked. The
  printed line names a group ("an opponent") and asks one question about all of them; the total over
  the group answers it, because the total is above zero exactly when one of them lost life. A
  `PlayerRef` would need `AnOpponent`, which the prompt already reserves for conditions.
- **`DistinctNameCount` is an amount, not a filter predicate.** The difference is between the
  objects counted, not a property any one of them has, so no filter can say it.
- **`CommanderCastsThisGame` defaults its `Which` to this object.** Every card that reads the count
  reads it about itself or about a commander it names; a required selector would make the common
  case a second spelling.
- **The non-mana keyword cost is a list on `GrantKeyword`, not a new record.** A printed keyword cost
  can be several things paid together, and everything else about the grant — which keyword, over what
  filter, with what N — is already this record's.
- **`CastAtInstantSpeed` is a condition and is answered from the cast, not the game.** A flag written
  as the spell is cast; see row 6. It is not a `ManaSpentOnThis`-shaped read and not a timing
  permission.
- **`EntersPrepared` sits beside `EntersTapped` as an `Effect` inside a replacement**, which is the
  shape the rule describes (CR 722.3a with 614.1c), and is refused outside one (L049).
- **`OfType` is a `CardType` and not an `ObjectFilter`.** The printed line narrows the *name* to a
  type; a filter would invite zone and controller riders that describe a board the choice never looks
  at.
- **`WouldDealDamage` gets `To` **and** `ToPlayer`, the shape `EnchantAbility` already uses** for
  "enchant creature or player". One field cannot say "a player or an object" without a union type the
  vocabulary does not have, and a filter alone would silently drop the player half.
- **CR numbers, every one read in `comprehensive-rules.txt` first.** Corrections to the brief:
  "any time a sorcery couldn't have been cast" is **307.5a**, which names the three things it checks
  (601.2h is paying costs and has nothing to do with it); prepare is rule **722**, and "enters
  prepared" is **722.3a**; "choose a land card name" is **201.2** with 205.2a, **not 201.3**, which
  is the interchangeable-names rule and says nothing about naming; "different names" is **201.2b**
  specifically. Confirmed as given: 601.2c, 119.3, 903.8, 702.21 (702.21a for the ward trigger),
  614.1.
