# P18 — canonical rewrite, a strict parser, an honest writer (wave 16)

## What landed

1. **`AttachedTo(Self)` in a trigger's filter is `IsOneOf(Attached)`.** A fourth canonical pass
   (`Agree/Canonical.Attached.cs`, run from `Derive` after `Retranslated`) rewrites the predicate
   when it is the `also` of a trigger record's `ObjectFilter` parameter, or one member of an
   `AllOf`/`AnyOf` there. The filters read are derived by reflection from every `Trigger` record's
   longest constructor (`Canonical.TriggerFiltersRead` prints them: `Dies.what`,
   `DealsDamage.source`, `Attacks.who`, `TappedForMana.what`, …). An `AttachedTo(Self)` anywhere
   else — an effect's filter, a trigger's *effect* — is a reading and is left as written;
   `AttachedTo(Triggering)`/`AttachedTo(Remembered)` in a trigger filter are kept too. The three
   pilot cards' trigger shape (Skullclamp's `Dies`, Sword of the Animist's `Attacks`, Sword of
   Feast and Famine's `DealsDamage` with `types: [Creature]`) is asserted as JSON.
2. **A strict parser.** `CardFileSerializer.Options` sets `UnmappedMemberHandling = Disallow`, so
   `TranslationPrompt.Parse`, `CardFileSerializer.Read`, the pipeline's file client and the API's
   `CardFilePool` all refuse a member no record has, naming it. A misspelled `nn` and an
   `Unsupported` marker in an `ObjectFilter` slot are both parse errors now (they read as an
   empty filter before). Every top-level file under `cards/*.json` (192) still reads
   (`SerializationTests.Every_card_file_on_disk_still_reads`), and the `cards/.lint` reports do
   too (`hasErrors` is a get-only member, which the strict mode counts as mapped;
   `CardFileWriterTests` round-trips one).
3. **An honest writer.** `CardFileWriter.Lowers` keeps a Verified file over a re-translation only
   when the existing definition carries no `Unsupported`/`UnsupportedContinuous` marker
   (`Linter.Walk`). A clean Verified file is kept (`KeptVerified`); a Verified file with either
   marker is replaced, its `Verification` cleared, and its lint report rewritten.

Tests: 49 `CanonicalTests` (5 new), 3 `CardFileWriterTests`, 3 `TranslationPromptTests`, 3 new
`SerializationTests`; the Pipeline project alone is 238 green (173 + 65 in the two namespaces), the
Cards project 193 green. `dotnet format --verify-no-changes` clean on all four projects.
