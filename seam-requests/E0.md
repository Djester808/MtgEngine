# E0 — seam changes the query layer needs

Every item below is a question a card asks that no record in `State/*` or `EffectContext` can
answer. Each one throws `NotImplementedException` naming the record, and each is covered by
`QueryTests.A_question_the_state_cannot_answer_names_the_record_instead_of_guessing`. None is
worked around.

## 1. Which object is a player's commander (CR 903.3)

Blocks `Selector.Commander`, `ObjectFilter.IsCommander` and `Condition.Lieutenant`. The command
zone is not the answer: a commander that has been cast is on the battlefield and still a
commander, and a card that starts in the command zone is not necessarily one (an emblem, a
conspiracy).

Needed: a flag on `GameObject` that survives a zone change, e.g. `bool IsCommander { get; init; }`,
set by E1 when the game is created from `PlayerStart.CommandZoneOracleIds` and carried across
every `ObjectMoved`. A `PlayerState.Commanders` list of object ids would not survive CR 400.7's
new-object rule.

## 2. What happened earlier this turn

Blocks `EnteredThisTurn`, `CastThisTurn`, `DealtDamageThisTurn`, `WasDealtDamageThisTurn`,
`Morbid`, `Revolt`, `Raid`, `Paradox`, `CastFromZone`, `FirstTimeThisTurn`, `SpellsCastThisTurn`,
`DamageDealtThisTurn`.

Needed: a per-turn record on `GameState` cleared at cleanup (CR 514.2), e.g.

```csharp
public sealed record TurnHistory(
    ImmutableList<ObjectId> EnteredThisTurn,
    ImmutableList<ObjectId> DiedThisTurn,
    ImmutableList<ObjectId> LeftBattlefieldThisTurn,
    ImmutableDictionary<PlayerId, ImmutableList<(ObjectId Spell, Cards.Zone From)>> SpellsCast,
    ImmutableDictionary<PlayerId, ImmutableList<ObjectId>> AttackedWith,
    ImmutableDictionary<ObjectId, int> DamageDealt,
    ImmutableDictionary<ObjectId, int> DamageReceived,
    ImmutableDictionary<PlayerId, int> DamageReceivedByPlayer,
    ImmutableList<int> AbilitiesResolved);
```

The query layer only reads it. Whoever owns the event that makes each fact should fold it in the
same `Apply` that makes the fact, so replay stays a pure fold.

## 3. What was paid to cast a spell (CR 601.2h)

Blocks `Adamant`, `WasKicked`, `WasKickedCondition`, `PaidAlternativeCost` and
`ManaSpentOnThis`. `StackEntry` records targets, modes and X but not the mana spent or the
optional costs paid.

Needed on `StackEntry`: `ImmutableDictionary<Color, int> ManaSpent`, `Cards.Zone CastFrom`, and
a list of the optional costs paid (kicker count, which alternative cost).

## 4. Per-object and per-player designations

Blocks `IsSuspected` (CR 701.60), `IsGoaded` (CR 701.15), `IsRingBearer` (CR 701.54),
`IsHarnessed` (CR 701.64), `IsCopy` for a permanent (CR 707.10), `YouAreMonarch` (CR 724),
`YouHaveInitiative` (CR 725) and `CityBlessing` (CR 702.131).

Needed: a designation set on `GameObject` (`ImmutableHashSet<string>` or one bool per
designation, plus `ImmutableList<PlayerId> GoadedBy`) and, on `GameState`, `PlayerId? Monarch`
and `PlayerId? Initiative`, plus a per-player designation set for the city's blessing.

## 5. Players remembered by key in `EffectContext`

Blocks `ChoosePlayer`, `ChosenPlayer` and `RememberedPlayer`. `EffectContext.Remembered` keys
objects, `Chosen` keys strings and `Stored` keys ints; there is nowhere to put a player an
earlier step chose, and encoding a `PlayerId` into the `Chosen` string would make the query
layer parse its own output.

Needed on `EffectContext`: `ImmutableDictionary<string, ImmutableList<PlayerId>> RememberedPlayers`.

## Note on a semantics choice, not a seam

`ObjectFilter.Subtypes` is read as a **disjunction** — "Elf or Goblin", "Island or Swamp" — which
is how card text almost always names more than one subtype, and matches the way `AnyTypes`
exists beside `Types` for card types. A conjunction ("Goblin Wizard") is not expressible in one
filter and has to be two. If the translator is going to emit conjunctions, the vocabulary needs
an `AllSubtypes` field; say so and E0 will follow it.
