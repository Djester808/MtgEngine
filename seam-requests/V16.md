## Decisions taken here

- **The existential opponent is an amount over a `PlayerFilter`, not a condition.** Both shapes the
  brief offered work; the max is the one that composes — the same amount answers "an opponent was
  dealt 7 or more" and "the greatest damage dealt to an opponent this turn" with one reader, where a
  bespoke condition answers only the first and a second card asking for the number would need a
  second record. It also sidesteps L041 by construction: a `PlayerFilter` is not a `PlayerRef`.
- **`PreventedDamage` is its own amount and not `TriggeringPreventedDamage` reused.** V15 separated
  dealt from prevented for the same reason; this separates *my* prevention, read as it applies, from
  *a* prevention, read by a trigger after the fact. Reusing the trigger's amount inside a replacement
  would read an event that has not happened yet.
- **The attack tax is a flag and not a new cost record.** The generic spelling
  (`Times(AttackersAgainst, 2)` in the cost) already plays and 32-odd stored cards use it; a new
  record would have made every one of them a candidate for re-reading. The flag says only what the
  generic scaling cannot: repeat this symbol.
- **`Mode.PaidCost` is a second field and not `Mode.Cost` with a flag on `ChooseMode`.** A budget
  price and a paid price are opposite claims about the same mana, and a bool that flips which one a
  stored `Cost` means would change the reading of the priced-mode cards already committed.
- **`Layout.Prepare` and `FaceRole.PrepareSpell` are appended last** to their enums, as
  `Placement.BottomRandomOrder` was, so no positional reading of a stored file shifts and
  `IrVersion` stays 1.
- **`ObjectFilter.NotHas` is appended after `Also`,** not placed beside `Has`, for the same reason.
- **CR numbers, every one read in `comprehensive-rules.txt` first.** Corrections to the brief:
  **spree is 702.172**, not 702.171 (that is Saddle); **the prepare layout is CR 722**, and the
  inset frame is 722.2a (there is no keyword rule for the frame — 702.180 is the *designation*, which
  the existing `Prepare` effect already cites); the negated keyword is **702.1** (702.9 is Flying
  itself, the example and not the rule). Confirmed as given: 102.2, 700.4, 615, 508.1h, 707.2, 201.2,
  605.1a.

  edit.
- **No card ids in the table.** V14 and V15 left the same debt and it is still open. Each gap came
  from the brief's printed phrase; the box went to the records. The ids for V14's nine, V15's eleven
  and these ten should be attached by searching `cards/` for the printed phrase — never by trusting a
  handed-over id — before the redo.
- **No lint for gap 3's other half, gap 7's face contents, or gap 10's mana road.** A
  `CreaturesDiedThisTurn` whose `Matching` demands a non-creature type is indistinguishable from a
  card that says "Goblins that died"; a `PrepareSpell` face with a permanent type line is wrong
  (CR 722.2 makes it a spell) but the type vocabulary is shared with every other face and the check
  would need the whole type table to be right; and a `TappedFor` rider paired with a source that has
  no mana ability is a fact about the board, not about the card. The one-spelling lines carry those.
- **`CantAttack.PerAttackingCreature` has no lint tying it to a coloured or Phyrexian symbol.** The
  flag is legal on a generic cost too — it just says the same thing the scaled generic says, twice —
  and refusing it would need the mana-string parser inside the linter. Worth adding when a reader
  for the cost string exists in `MtgEngine.Cards`.
- **`GreatestSameNameCount` takes no player.** Every printed shape puts the controller in the filter
  ("lands **you control** with the same name"), so the filter carries it; a card that asks about a
  group across the table writes `ControlledBy: null` and gets it.
