## Decisions taken here

- **The token's size is on the spec, not a `SetPt` after the `CreateToken`.** The brief offered
  both. CR 111.3 makes the creating ability's defined values the token's copiable text, which a
  layer-7b setting is not: a copy of the token would be 0/0, a second `SetPt` would overwrite it,
  and a 0/0 token is a state-based action away from the graveyard in the window before the setting
  applies. Two fields rather than one `PrintedStat`, because the existing `Power`/`Toughness` are
  `int?` and a stored file must keep reading.
- **The per-type edict is a flag on `Sacrifice`, not a new record.** Everything else about the
  sentence — who sacrifices, what the rule looks at, what is remembered — is already this record's,
  and the wave-26 each-player edict road is the code that would have been duplicated.
- **The once-per-turn limit and the additional cost are two fields on the permission.** A separate
  ability for the cost would be paid at resolution instead of as the spell is cast, and a separate
  counter would count casts of the card rather than casts the permission allowed.
- **`CantEnterBattlefield` takes a filter and no zones of its own.** The printed zones belong to the
  cards being forbidden ("creature cards **in graveyards and libraries**"), which is a filter, and a
  card that names no zone must be able to say so — a record with a required zone list would force
  every-zone to be spelled out and make the two restrictions look alike.
- **`InAnyOf` is a list on `ObjectFilter`, not a repeated filter or an `IsOneOf`.** A repeated filter
  needs an `AnyOf` of filters the vocabulary does not have, and a predicate would hide the zone from
  every reader that already looks at `In`.
- **`CastFrom` on `CantCastSpells` is the record's own field.** The filter's single-zone `CastFrom`
  stays what it is (one spell's zone); the restriction's list is a different claim.
- **`PhasedOutIs` is an expectation and not a card record.** The card's own line is the existing
  `PhaseOut` effect; this is what a scenario asserts afterwards.
- **CR numbers, every one read in `comprehensive-rules.txt` first.** Corrections to the brief:
  the token's characteristics are **111.3** (111.4 is its name and subtypes); sacrifice is
  **701.21** (701.16 is Investigate, and there is no 701.21b — the simultaneity is CR 101.4);
  the permanent types are **110.4** (205.2a is the *card* types, which include instant and sorcery).
  Confirmed as given: 702.40 for storm, 702.26b for the phased-out status. The two the brief left
  open: the once-per-turn permission is **118.8** with **116.2a**, and the forbidden entry is
  **613.11** with 608.3e and 111.5.
