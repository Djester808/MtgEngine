## 2. `Pilot.Evaluate` can never agree (bug, `MtgEngine.Cards.Pipeline/Pilot.cs`, not owned)

`Evaluate` lints each single-model reading through
`FileFor(card, definition, [model], agreed: false, ...)`, which sets
`Status = ImplementationStatus.Disputed` with `Candidates = null`. `Linter.CheckStatus` then
raises L013 ("A Disputed file must keep both readings in Candidates") as an **error** on every
reading, so `good` is always empty, `agreed` is always false, and every card in the pilot report
comes out disputed with no file written. The same applies to the `repair` branch in `RunAsync`,
which sees `lint.HasErrors` for every reading and re-asks the model for a repair it does not need.

`Agree/AgreeStage.cs` does not copy this: a candidate reading is linted in a file with
`Status = Translated`, and `Disputed` is only set on the file that actually carries both
candidates. If the pilot numbers are being read as a decision point, they are wrong by this bug;
the fix in `Pilot.cs` is to pass `ImplementationStatus.Translated` when linting one reading, or
to call `AgreeStage.Agree` instead of `Evaluate`.
