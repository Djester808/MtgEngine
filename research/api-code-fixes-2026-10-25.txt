Implemented

  session lock; isolate private delivery by game/account; serialize delivery;
  validate nested commands; share cold loads and release unused session retention.
- Persist game event batches with expected revision checks instead of rewriting
  all prior events. Migration rollback folds batches back into the legacy log.
- Collections: preserve etched quantities on printing adoption; share published
  post/comment cleanup across deletion paths; preload merge/move destinations;
  provide atomic one-copy swaps and a narrower reader interface.
- Cache collection read snapshots by owner, update timestamp and catalog version.
  Publish correlated catalog indexes atomically; stream array imports; preserve
  requested sorting and filters; expire rulings; write disk caches atomically.
- AI: count every finish; preserve both commanders and their color identities;
  assess complete partial decks; enforce selected printing budgets; propagate
  cancellation; centralize SSE transport and safe error handling. The sibling
  client carries the preview budget into the apply request.
- Accounts/community: consistent reserved names; case-insensitive unique account
  indexes; expired authentication retention cleanup; SQL-ranked player limits;
  bounded forum list/comment reads; accurate republish counts; request validation;
  shared admin operation gate; explicit rejection of unsupported time windows.
- Remove unused forum dependency and EDHREC helpers, share slug conversion, and
  move candidate/commander browsing business logic out of controllers.
- Fix parser/classifier edge cases and historical migration defects affecting
  fresh database creation and acquisition metadata during row consolidation.
- Detach failed AI cache inserts so they cannot poison subsequent business saves.
- Track in-place collection tag edits using structural comparison and cloned
  snapshots; tested with independent SQLite contexts and successive saves.
